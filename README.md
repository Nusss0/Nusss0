## 🛡️ About Me

I'm **Stevanus** — a Computer Science student at **Institut Teknologi Bandung (ITB)** with a strong focus on offensive security.

I enjoy breaking down how systems behave, identifying weak assumptions, and turning findings into practical hardening ideas. I’m intentionally building strong fundamentals through disciplined labs, responsible testing, and continuous iteration.

- 🔍 Interested in penetration testing and vulnerability assessment
- 🧪 Learning through CTFs, security labs, and attack-simulation workflows
- 🌐 Exploring web application, network, and system security
- 🧠 Building durable cybersecurity + software engineering fundamentals
- ⚡ Motto: understand the system, test the assumptions, improve the result
